# รูปแบบบทเพลงและวงดนตรีสากลในแต่ละยุคสมัย

HTML presentation (ไฟล์เดียว, self-contained) สำหรับวิชาศิลปะพื้นฐาน 5 (ศ33101)
หัวข้อ **รูปแบบบทเพลงและวงดนตรีสากลในแต่ละยุคสมัย** — ระดับชั้น ม.6/7

## วิธีใช้
เปิด [`index.html`](index.html) ในเบราว์เซอร์ แล้วกด `F11` เพื่อเต็มจอ (รองรับจอโปรเจคเตอร์/จอทัช 16:9)

- เปลี่ยนสไลด์: ปุ่ม ◀ ▶ บนจอ, แถบ timeline, หรือลูกศร `←`/`→` / `Spacebar`
- ปุ่ม **▶ ฟังตัวอย่าง** แต่ละยุค: เปิดคลิป YouTube ในแท็บใหม่
- **เกมทายยุคจากเสียง**: เล่นเสียงตัวอย่าง (public domain) ในหน้าเว็บโดยไม่โชว์ภาพ → ทาย → เฉลย
